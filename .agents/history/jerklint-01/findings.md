# Jerklint 01

## Findings

1. **High** `src/Router.ts:70-85`: After-middleware decorations are discarded for plain handler values. `Router.dispatch()` creates and binds `response`, lets after-hooks mutate it, then returns `respond(result)` instead of that response. Plain objects therefore create a second `Response`, losing headers from cache, CORS, CSP, cookies, rate limiting, and request IDs; direct `Response` results happen to preserve them. Normalize once, return the bound `response`, and treat any after-hook replacement as the new single final response.
2. **High** `src/Router.ts:35-36`: Top-level middleware has no coherent request lifecycle. `RouterOptions.middlewares` runs inside every candidate-handler dispatch, so failed candidates regenerate request IDs/nonces and consume rate-limit counts at `src/middleware/requestId.ts:18-21`, `src/middleware/csp.ts:53-58`, and `src/middleware/rateLimit.ts:33-38`. A before short-circuit skips all after-hooks at `src/Router.ts:61-68`; normal after-hooks run in registration order at `src/Router.ts:76-84`, making `[cookies(), csrf()]` satisfy CSRF before-order but flush cookies before CSRF queues its token at `src/middleware/cookies.ts:29-47`, `src/middleware/csrf.ts:22-28`, and `src/middleware/csrf.ts:59-68`. `use()` duplicates phase policy by casting after-hooks into before-hooks around `noop` at `src/handler/use.ts:13-41`. Run global middleware once around route selection, finalize both handler and short-circuit responses, unwind entered after-hooks in reverse order, and make `use()` delegate to that one phase runner.
3. **High** `src/middleware/cookies.ts:25-47`: Reusable middleware retains request-local state across requests. `cookies()` shares `parsed` plus never-cleared `pending`; `rateLimit()` shares `lastResult` at `src/middleware/rateLimit.ts:24-68`, while Router reuses middleware instances at `src/Router.ts:13-18`. Sequential requests replay cookies; concurrent requests can observe another request’s cookies or rate result. Keep only immutable configuration/process-wide stores in factories; bind one request-scoped cookies/rate result object in `before` and consume it in `after`.
4. **High** `src/router.types.ts:24-31`: `bind()` is an unscoped mutation channel. It accepts arbitrary keys and mutates the shared context/container at `src/Router.ts:49-54`. `prefix()` permanently rebinds stripped `url` before a child can fall through at `src/handler/prefix.ts:26-35`, and `pattern()` leaves `params` from a non-producing route at `src/handler/pattern.ts:25-36`, so sibling behavior depends on earlier failed handlers. Give nested dispatch scoped binding overlays that unwind after dispatch; pass prefix URL and params through the child scope without changing the parent request context.
5. **High** `src/handler/pattern.ts:17-24`: Method matching and HTTP error policy are disconnected. `pattern()` treats a pathname match plus method mismatch as terminal `MethodNotAllowed` data, so `get("/x")` before `post("/x")` blocks POST. `respond()` serializes the returned error as ordinary JSON, while `Router.route()` maps every thrown error to 500 at `src/Router.ts:31-45` and `src/Router.ts:97-108`, despite exported status-bearing errors at `src/RouterError.ts:3-42` and README’s thrown-error contract at `README.md:369-379`. Let wrong-method candidates fall through, decide 405 centrally after pathname/method candidacy is known, and use one thrown `RouterError` boundary that owns status/message serialization and logs only unexpected errors.
6. **Medium** `src/router.types.ts:24-46`: Handler/context types erase their own domain contract. `RequestHandler`/`ResponseHandler` accept `any`, return `unknown`, and `RouterBind` is an arbitrary `any` map; consumers recreate magic `assets`, `params`, `cookies`, `cspNonce`, and `requestId` shapes through local intersections. Core `RouterOptions` also imports concrete `@sigitex/bind` `Container` at `src/router.types.ts:2` and `src/router.types.ts:48-52`. Define an awaitable handler-result type plus generic environment/binding context, make every public helper declare required/provided bindings, and isolate concrete DI invocation behind a typed adapter boundary.
7. **Medium** `src/bun/bun.ts:10-14`: Runtime initialization is disguised as route matching. `bun()` and `cloudflare()` at `src/cloudflare/cloudflare.ts:13-28` return ordinary fallthrough handlers whose only job is `bind({ assets })`; `assets()` at `src/handler/assets.ts:5-8` and `app()` at `src/handler/app.ts:6-11` assume list order supplied that binding. Add an explicit request-context initialization phase in route options/construction and validate platform bindings before matching begins.
8. **Medium** `src/middleware/bodyLimit.ts:10-42`: `bodyLimit()` promises body enforcement but checks only an untrusted declaration. It relies on truthy `Content-Length` plus permissive `parseInt`, and MIME `startsWith`; streamed, absent, or understated lengths and `application/jsonp` bypass the named policy. Enforce bytes at the body-reading boundary and compare a normalized exact media type, or narrow the API/docs to `contentLengthLimit` if actual stream enforcement is intentionally excluded.
9. **Medium** `src/middleware/cors.ts:33-75`: CORS/cache header policy admits invalid and order-dependent states. CORS swallows any `OPTIONS` plus `Origin` request without requiring `Access-Control-Request-Method`, and permits wildcard origin with credentials at `src/middleware/cors.ts:99-119`. CORS appends `Vary: Origin`, while cache replaces `Vary` at `src/middleware/cache.ts:22-34`, making stack order observable. Recognize real preflights, reject or safely reflect wildcard-plus-credentials, and merge case-insensitive `Vary` tokens rather than replace the field.
10. **Medium** `src/middleware/www.ts:4-13`: Redirect helpers use inaccurate predicates and mutate shared URL state. `www({ secure: true })` on `http://www.example.com` prefixes `www.` again because host and protocol checks share one guard; `www()` and `https()` at `src/middleware/https.ts:4-10` mutate the request context URL. Clone URL, transform hostname and protocol independently, and redirect only when the clone changed.
11. **Medium** `src/env.d.ts:1-1`: Environment and Cloudflare binding contracts are hidden globals/assertions. Public types rely on empty ambient `Env` declarations here and at `src/cloudflare/env.d.ts:1-1`; Cloudflare reads an arbitrary option key through `as any` and binds it without checking `fetch` at `src/cloudflare/cloudflare.ts:8-27`. Parameterize router/context by exported environment type and validate the selected Cloudflare binding once, at adapter setup, with a key-specific failure.
12. **Medium** `src/middleware/csp.ts:9-46`: CSP schema/configuration has two drifting representations. Source fields exist in `CspOptions` and again in weak `directiveMap`, forcing casts at `src/middleware/csp.ts:73-99`; construction snapshots `usesNonce` but later rereads caller-owned arrays, so mutation can yield `'nonce-undefined'` at `src/middleware/csp.ts:49-64`. Derive directive option keys from one `as const` declaration and snapshot normalized immutable options once.
13. **Medium** `src/index.ts:1-9`: Public API shape exposes internal and magic machinery. Root and nested wildcard barrels make every nested export public, including `noop`, which source/docs call internal, through `src/handler/index.ts:1-7`. `mount()` probes undocumented `__mount`/`container` through `any`, with no producer found in source, docs, or direct dependency at `src/handler/mount.ts:5-11`. Middleware barrel also mixes `RouteMiddleware`, `RequestHandler`, higher-order handlers, and raw `ResponseHandler` at `src/middleware/index.ts:1-17`. Use an explicit supported root export list, keep `noop` private, delete the producerless `__mount` YAGNI branch, and place/name exports by composition role.
14. **Medium** `src/Assets.ts:2-4`: `Assets` leaves pathname and missing-file ownership implicit. `Assets.static(string)` does not encode a leading slash; Cloudflare concatenates `origin + path` at `src/cloudflare/cloudflare.ts:31-42`, while Bun tolerates relative input at `src/bun/bun.ts:17-40`. Adapters normalize missing files to `undefined`, but `assets()` redundantly checks status 404 at `src/handler/assets.ts:5-11`. Require or normalize one absolute-pathname contract and make adapters solely responsible for mapping missing files to `undefined`.
15. **Medium** `tsconfig.test.json:9-17`: No repository test defends public lifecycle contracts. Test config targets `tests`, that directory contains no TypeScript files, and the script explicitly passes with no tests at `package.json:38-42`. Add behavior tests around response decoration of object results, once-per-request middleware, short-circuit finalization, reverse unwind, concurrent request isolation, same-path multi-method routes, prefix fallthrough, and adapter ordering; each should exercise public `route()` behavior rather than source internals.
16. **Medium** `src/middleware/rateLimit.ts:24-29`: Rate-limit option and algorithm contracts are inaccurate. Zero, negative, or non-finite windows reach modulo arithmetic and can emit `NaN` reset headers at `src/middleware/rateLimit.ts:81-106`; implementation uses fixed epoch buckets while README calls it sliding-window at `README.md:303-318`. Validate finite positive window/non-negative max at construction and document fixed-window semantics unless a true sliding store is implemented.
17. **Low** `src/router.types.ts:24-25`: `RouterBind` says synchronous `void`, but implementation is `async` at `src/Router.ts:49-55`; every caller relies on immediate mutation, and the current body performs no asynchronous work. Remove `async` and keep binding explicitly synchronous.
18. **Low** `src/handler/prefix.ts:26-33`: `prefix()` excludes its exact root. Appending `/` then using only `startsWith(root)` means `prefix("/api")` matches `/api/...` but not `/api`. Accept equality plus descendant boundary and map exact root to child `/`.
19. **Low** `src/Router.ts:11-18`: Readonly-looking configuration remains caller-owned mutable state. Router stores caller arrays directly; option types expose mutable nested arrays across body limit, CORS, CSP, and CSRF, and cookies retains mutable option objects until response time. Accept readonly arrays, snapshot router handlers/middleware in the constructor, and snapshot or serialize phase-sensitive middleware configuration at construction or queue time.

## Scorecard

- DRY: concern — error/response-finalization and asset/header policies have multiple owners.
- KISS: concern — `use()` phase emulation and mutable nested dispatch make simple composition nonlocal.
- YAGNI: concern — producerless `__mount` and public internal `noop` add unsupported surface.
- SOC: fail — one handler pipeline mixes initialization, matching, DI, middleware, response coercion, and errors.
- Cohesion: concern — core type bag and middleware barrel combine distinct roles.
- Coupling: fail — stack order, candidate count, dynamic keys, and shared context control behavior.
- Dependency Direction: concern — core public types depend on concrete DI and ambient platform contracts.
- Law of Demeter: pass — no material nested-object traversal smell was found.
- Immutability: fail — request data lives in shared closures and URL/context/config objects are aliased.
- Declarative Shape: concern — HTTP/CSP tables are strong, but lifecycle/error policy remains scattered imperative code.
- Implicit Contracts: fail — ordering, scope, sync binding, setup, path, and throw/return rituals are unencoded.
- Abstraction Pressure: fail — weak central lifecycle/state boundaries force duplicated leaf policy while speculative hooks remain.
- Naming/API Clarity: fail — `bodyLimit`, `mount`, `RouterError.code`, and fixed/sliding semantics overpromise or obscure behavior.
- Locality: fail — understanding one response requires tracing Router, grouping handlers, bindings, and middleware phases.
- Predicate Accuracy: fail — body, preflight, redirect, method, and prefix predicates accept or reject the wrong shapes.
- Construction Phase Separation: fail — platform setup, request wiring, route selection, and response finalization share one execution protocol.
